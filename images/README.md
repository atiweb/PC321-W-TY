# Images

This folder contains images for documentation.

## Required Images

Please add:
- `pc321-w-ty.png` - Photo of the PC321-W-TY device
- `wiring-diagram.png` - Wiring diagram (optional)
- `localtuya-setup.png` - Screenshots of LocalTuya configuration (optional)
- `energy-dashboard.png` - Screenshot of Energy Dashboard (optional)

## Image Sources

You can obtain device images from:
- Your own photos
- Manufacturer documentation (OWON)
- Product listings (with appropriate permissions)

## Adding Images

1. Save images in this folder
2. Reference them in markdown files using:

```markdown
![Alt Text](images/filename.png)
```
